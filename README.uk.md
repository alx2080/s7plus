# S7 Plus

[English](README.md) | **Українська**

Користувацька інтеграція Home Assistant для контролерів **Siemens S7-1200 і S7-1500** за протоколом **S7CommPlus** — тим самим, яким користуються TIA Portal і панелі оператора. Контролер і теги налаштовуються в браузері, без YAML. Працює на бібліотеці [`s7commplus`](https://pypi.org/project/s7commplus/).

> ⚠️ `s7commplus` — неофіційна реалізація протоколу на стадії бета (версія 0.2.0), Siemens її не підтримує. Спершу перевірте інтеграцію на контролері, який не керує відповідальним обладнанням.

## Можливості

- **Символьний доступ за іменами тегів.** Тег вибирається з каталогу, прочитаного із самого контролера: спочатку блок (DB або область I/Q/M), потім тег, із фільтром за іменем. Працює з **оптимізованими** блоками даних, **вмикати PUT/GET не потрібно**.
- **Адреса вручну** `DB.зсув` — запасний варіант для неоптимізованих блоків, якщо каталог прочитати не вдалося.
- **Типи:** BOOL, BYTE, WORD, DWORD, LWORD, SINT/USINT, INT/UINT, DINT/UDINT, LINT/ULINT, REAL, LREAL, TIME, LTIME, STRING/WSTRING/CHAR. Члени структур доступні як окремі теги. Масиви не підтримуються.
- **Об'єкти:** сенсор, бінарний сенсор, вимикач, число (уставки), вибір (значення ↔ режим). Множник і зсув для числових тегів.
- **Групове читання:** багато тегів одним запитом. Відхилений контролером тег не заважає решті.
- **Швидке опитування** окремих тегів зі своїм інтервалом.
- **Службові об'єкти:** «Зв'язок» (з настроюваним тайм-аутом втрати зв'язку) і «Режим CPU» (RUN/STOP, якщо прошивка його повідомляє).
- **Перевірочне читання** тегу перед збереженням.
- **«Оновити адреси тегів»** після зміни програми контролера: теги заново знаходяться за іменами.
- **Копіювання тегів** з іншого контролера.
- **Одна сесія на контролер** для всіх тегів: у S7-1200 мало вільних з'єднань, інтеграція не забирає їх у панелей і TIA Portal.
- Модель контролера й прошивка на картці пристрою, діагностика.
- Інтерфейс англійською, українською та російською.

## Підготовка контролера в TIA Portal

1. **Рівень доступу.** «Повний доступ» без пароля або пароль, який вводиться під час додавання контролера.
2. **Видимість тегів.** У потрібних тегів у блоках даних має стояти прапорець «Accessible from HMI/OPC UA/Web API» — типово його ввімкнено.
3. **TLS.** S7-1200 з прошивкою V4.5+ і S7-1500 V2.9+ приймають лише TLS — прапорець TLS в інтеграції типово ввімкнено. Сертифікати вказувати не потрібно (перевірено на CPU 1215C, проєкт TIA Portal V21). Для перевірки сертифіката контролера можна вказати файл CA, наприклад `/config/s7/ca.pem`.
4. **Адреси вручну.** Для блоків даних, до яких звертаєтеся за адресою, вимкніть «Optimized block access». Для вибору з каталогу це не потрібно.

## Встановлення через HACS

1. HACS → «⋮» (справа вгорі) → **Custom repositories**.
2. Repository: `https://github.com/alx2080/s7plus`, Type: **Integration** → **Add**.
3. Знайдіть інтеграцію в HACS → **Download** → перезапустіть Home Assistant.

Нові версії HACS покаже сам, як звичайне оновлення.

## Встановлення вручну

1. Скопіюйте `custom_components/s7plus` у `config/custom_components/`.
2. Перезапустіть Home Assistant (під час першого запуску встановиться `s7commplus`).
3. «Налаштування → Пристрої та служби → Додати інтеграцію → S7 Plus».
4. На картці контролера — **«+ Додати тег»** → тип об'єкта → «Обрати з тегів контролера».

Перше читання каталогу на великій програмі може тривати до хвилини. Потім каталог кешується на 10 хвилин, тож наступні теги додаються швидко.

## Якщо щось не працює

- **Не підключається:** спробуйте «Підключатися як» → «Інженерна станція». Перевірте, чи не потрібен TLS або пароль.
- **Каталог не читається:** додавайте теги вручну за адресою DB. Якщо не допомогло, створіть [Issue](https://github.com/alx2080/s7plus/issues) і додайте журнал із `s7commplus` у режимі налагодження (перевірте, що в ньому немає паролів і адрес):
  ```yaml
  logger:
    logs:
      s7commplus: debug
      custom_components.s7plus: debug
  ```
- **Тег перестав читатися після завантаження програми:** параметри → «Оновити адреси тегів».
- **Помилки на великих запитах:** зменште «Тегів в одному запиті».

## Для розробників

Переклади генерує `tools/make_translations.py`. Перевірка зв'язку з контролером — `tools/s7probe.py`.
